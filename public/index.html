How a message gets sent
  • 👩‍💼 An agent takes an action in Shopify — that is the only trigger.
  • 🔔 Shopify fires a webhook to a Cloudflare Worker (HMAC-verified).
  • 🧩 The Worker pulls order and customer data from Shopify, logistics from Dobesell, ticket context from Freshdesk.
  • 📝 The matching template is filled, in the customer's language and tone.
  • 📤 It goes out on both channels, and every send is written to an audit log.

How the feed is wired
  • ⏱️ A Cloudflare Worker cron polls homekode.com/products.json and the collection endpoints.
  • 🗃️ Each poll is snapshotted to Supabase.
  • 🔍 The next poll is diffed against the last one, so the feed shows change events, not a product list.
  • 🏷️ Events detected: new arrival, price drop, price increase, back in stock, sold out, collection updated.
  • 🔄 The page re-renders on its own — no manual refresh.

Stage 1 · Non-negotiables

Security & delivery

This app will send real messages to real customers. That's a responsibility, so the guardrails come before the features. 🔐

Security posture
  • 🗝️ No key ever reaches the browser. All secrets live in Cloudflare Worker environment bindings.
  • ✍️ Every Shopify webhook is HMAC-verified before it's trusted.
  • 🔁 Sends are idempotent — one action, one message, even if a webhook is delivered twice.
  • 👤 Sign-in required, with roles: Owner (you), Editor, Viewer.
  • 🧾 An audit log of every message: who, what, when, to whom, on which channel, and the result.
  • 🛑 A global kill switch that stops all outbound sending in one click.
  • 🧪 A dry-run mode that renders and logs a send without dispatching it.
  • 🙈 Customer data is rendered, never stored beyond what the audit log needs.
Deliverability & compliance
  • 📧 SPF, DKIM and DMARC on homekode.com — without these, mail goes to spam.
  • 💬 WhatsApp templates must be pre-approved by Meta; free-form text outside a 24-hour customer-initiated window is not permitted.
  • 🌍 Written for a multi-national Middle East audience: plain English, no idioms, no slang, AED, UAE address format.
  • ⏰ Send windows respect customer care hours, 9am–9pm, seven days a week.
  • 🔕 A customer who opts out of WhatsApp still receives email.
Outstanding items are credential handovers, not decisions. Each is requested only at its own module. Nothing is blocked today. ✅
